# Python Advanced Practice Sets

This folder adds real-world practice material for each numbered topic in `Python Advanced`.

Each topic has two companion files:
- `*_problems.md` for scenario-driven exercises
- `*_solutions.md` for worked solutions with explanations and code

Coverage in this folder:
- `01_decorators`
- `02_context_managers`
- `03_generators`
- `04_combined_challenges`
- `05_metaclasses`
- `06_descriptors`
- `07_concurrency`
- `08_closures_scoping`
- `09_itertools_functools`
- `10_dataclasses_slots`
- `11_abc_protocols`
- `12_magic_methods`

`temp.py` is intentionally ignored because it does not look like a finished topic file.
